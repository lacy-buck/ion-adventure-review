# Ion Adventure Review

Create a review app to help high school chemistry students study for an upcoming assessment.  Do not use any of the exact same questions or substances.  Keep the ideas of the questions, but ask them in a different way so it's not like they are practicing the test.  Ask me a series of questions as you are putting together the plan before building.
